# Loop537 shared-gate seed replay 입력과 dashboard 계약 보고

Loop537은 Loop536 residual54 follow-up을 같은 38-row 계열 반복으로 다시 갈지 않도록, projection에 이미 있는 shared-gate 근거를 runtime 입력까지 보존하는 회차다. 새 runtime replay나 full375 대형 런은 실행하지 않았다. 이번 산출물은 35건 replay 입력과 9건 repair lane을 만든 것이며 approval 근거가 아니다.

- `tools/build_projection_followup_queue.py`는 prior runtime `FAIL_RUNTIME_PROMOTION_BLOCKED` 29건을 projection official URL 유무로 나눈다.

- URL이 없는 9건은 `projection_followup_official_url_repair_required`와 `shared_gate_runtime_block_repair_required`로 남긴다.
- `expert_main.py`는 `_loop_projection_followup` seed를 읽어 exact source-native safe projection, current-work scope, official URL, work-as-work discussion, hard-negative flag 없음 조건에서만 promotion seed를 적용한다.
- `PostInput`에 `projection_followup` 필드를 추가했고, loader/result에 `_loop_projection_followup`을 보존한다.
- runtime replay manifest에는 `requested_parallel=16`, `expected_effective_parallel=16`, dashboard 계약 `WEB_DASHBOARD_REQUIRED_FOR_TEST_RUNS`, `dashboard_url=http://127.0.0.1:8080`, `--no-dashboard` 금지를 기록한다.
