# Loop518 테스트런 웹 대시보드 템플릿 동기화 보고

Loop518은 새 runtime replay가 아니라 테스트런 진행상황 관측 계약을 다시 동기화한 회차다. 현재 dashboard `http://127.0.0.1:8080`은 health `ok=true`, `standalone=true`, `pid=9320`로 응답했고, 최신 상태는 Loop515 runtime replay `57/57`, `progress_pct=100.0`, `parallel_count=16`, `batch_running=false`다.

## 변경

- `goal.md`의 오래된 Loop 2 canary 예시에서 `--no-dashboard`를 제거하고 `--parallel 16`으로 고쳤다.
- `docs/devs/GOAL_REGRESSION_SAFE_GROUNDING_LOOP.md`의 Targeted canary 계약을 `--parallel 16` + dashboard 기본 ON으로 갱신했다.
- `docs/devs/SAMPLING_AND_PARALLEL_TEST_GUIDE.md`에 직접 `expert_main.py` 실행 전 dashboard health 확인 규칙을 추가했다.

- dashboard policy: `WEB_DASHBOARD_REQUIRED_FOR_TEST_RUNS`
- runtime parallel policy: `LOCKED_TO_16_BY_USER`
- runtime replay: `NOT_RUN_AFTER_DOC_SYNC`
- full375 collateral: `NO-GO / not rerun`
- search evidence: `REVIEW`
- semantic quality: `REVIEW-LOCKED`
- full scan approval: `false`

대시보드는 진행 관측 도구일 뿐 semantic/full_scan approval 근거가 아니다. 완료 기준은 계속 `full375 collateral GO + full_scan 경로 정의`다.
