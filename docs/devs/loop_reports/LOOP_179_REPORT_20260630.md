## 3. 연구/근본원인 분석

전문가 협업에서 지적된 한계는 “여러 local guard가 서로 다른 public-title publish 경로에서 우회될 수 있다”는 점이었다. Loop179는 그 문제를 완전히 끝낸 것이 아니라, 먼저 공통 decision object를 만들어 고위험 경로의 publish/hold 판단을 테스트 가능한 구조로 끌어올렸다.

핵심 구분은 그대로 유지한다.

- official title/page existence는 row-level work discussion evidence가 아니다.
- candidate 보존과 public `official_title` promotion은 분리한다.
- `safe_resolved` 누수는 `PromotionDecision.publish_allowed=false`일 때 `promotion_blocked`로 남겨야 한다.
