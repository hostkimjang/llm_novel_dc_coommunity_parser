## 해석

Loop388은 런타임이 실제 row를 내는지 먼저 증명하고, 그 다음 코드 변경이 row 의미 품질을 개선하는지 같은 입력으로 비교한 회차다. 기존 문제는 검색이 완전히 고장난 것이 아니라, 이미 확보된 공식 상세 URL이 author_bridge 제목과 exact match인지 확인하지 않아 잘못된 공식 후보가 gap을 닫아버리는 구조였다.

이번 수정은 특정 작품명 substring cue를 늘리지 않고, author_bridge title hint마다 공식 상세 페이지 title이 정확히 닫혔는지 검사한다. 따라서 `혼후순결` 같은 잘못된 공식 후보가 있어도 `이세계에서 사이비로 살아남기`에 대한 official detail gap은 유지되고, 보충 검색과 fetch가 실행된다.
