## 연구·근본원인

- Root cause 1: Loop461에서는 title/body work-review 표면이 있는데도 `21세기 무림 웹소설`, `21세기 무림 노벨피아`, `시리즈 21세기 무림 작가`류 공식 probe가 저특이/poison pruning에 걸렸다.

- Fix boundary: 특정 `post_id`, `21세기 무림`, `아생갤` 값을 생산 코드에 넣지 않았다. 일반 조건은 `current_from_official`, `best_alt_from_official`, `current_has_official_keyword_support`, `current_has_structural_alias_support`, support strength 비교다.
- Trade-off: recall을 열되, 공식 후보 간에도 원문 표면과 공식 detail 근거가 붙은 후보를 보호해 precision 손실을 줄인다.
