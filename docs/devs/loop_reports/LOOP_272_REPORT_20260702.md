## 회차 요약

- 날짜: `2026-07-02`
- 범위: `audit_expert_run_health.py`가 search-health direct probe, row-level `search_health`, worker log 검색 저하 신호를 하나의 `search_evidence` gate로 분리 기록하게 했다.

  - checkpoint row의 `identity.search_health`와 `search_health_flags`를 집계한다.
  - worker log의 `search_timeout`, `search_degraded_detected`, `search_upstream_zero`, `search_bridge_after_filter_zero`를 gate 입력으로 요약한다.
- `tests/test_audit_expert_run_health.py`
  - light-health-only는 `SEPARATE_AUDIT_REQUIRED`가 되어야 하는 계약을 추가했다.
  - manifest direct search health 실패는 `NO-GO`가 되어야 하는 계약을 추가했다.
  - row/log 검색 저하 관측은 `REVIEW`가 되어야 하는 계약을 추가했다.
