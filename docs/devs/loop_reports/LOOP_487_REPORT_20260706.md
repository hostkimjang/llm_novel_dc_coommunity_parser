Loop486 exact9의 expected-title mismatch 2건을 residual 단건 런으로 반복하지 않고 stable alias 계약으로 먼저 수리했다. `11685987`은 `괴담동 -> 괴담 동아리` 안정 alias가 `[괴담 동아리] 겨울` 파생/패러디 상세 hit에 밀린 케이스이고, `11692444`는 `엑칼뽑 -> 엑스칼리버 뽑습니다` 안정 alias가 더 긴 별도 공식작 `엑스칼리버는 뽑았는데 신탁이 엉터리잖아!`에 밀린 케이스다.

- alias syllable이 canonical title에 더 조밀하게 결속되면 loose official search collision보다 stable alias를 우선한다.
