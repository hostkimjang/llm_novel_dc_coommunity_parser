# Loop408 보고서 - 11705245 context-only thematic publish 계약

## 회차 요약

- 목적: Loop406 golden18 실패 `11705245`에서 `context_only`와 `thematic_overlap_only`를 동시에 기록한 publish가 `하남 남자` public title로 저장되는 경로를 공유 publication contract에서 막는다.
- 신규 full375/bounded/N5/golden18 대형 런과 동일 38-row parent packet replay는 열지 않았다.
- 결론: code/unit contract는 `GO_UNIT`이다. Loop406 저장 row projection에서 `safe_resolved / publish_allowed=true / 하남 남자`가 `promotion_blocked / publish_allowed=false / official_title=null`로 내려간다.

## 원인

`11705245` 원문은 제목 `하남자 재밌냐`, 본문 `주인공 첨부터쌤?`, 댓글 `ㄴㄴ` 수준의 짧은 반응이다. Loop406 결과는 decision reason에 `context_only`, `thematic_overlap_only`, `row_discusses_work_as_work`, `official_detail_url`을 함께 들고 있었고, hard bridge 없이 `scope_current_work`로 publish됐다.

기존 same-url mismatch guard는 후보 목록 안에 같은 URL의 정식 상세 제목이 있을 때 잘 막는다. 이번 보강은 후보 목록이 약하거나 stale gate URL이 섞여도, publish decision 자체가 `context_only + thematic_overlap_only`를 기록했고 direct image/title/url/verified alias hard bridge가 없으면 public identity를 후보 보존 상태로 되돌린다. R1 하드코딩 cue 리스트나 `post_id` 예외는 추가하지 않았다.
