# Loop401 저특이 alias non-work 계약 보고서

## 회차 요약

- 날짜: 2026-07-04
- 기준 HEAD: `c035bfdf`
- 범위: 신규 full375/bounded/N5 대형 런과 동일 38-row parent packet replay는 발주하지 않았다.
- 목적: Loop399 golden18 실패 `11713212`에서 일반 부사 `가장`이 `SSS급 죽어야 사는 헌터` alias로 해석되어 public title publish되는 경로를 런 반복 없이 단위 계약으로 막는다.
- 결론: 코드 계약은 `GO_UNIT`이다. Runtime replay after patch는 `NOT_RUN_AFTER_PATCH`이며, expected-answer와 full375 approval은 갱신하지 않는다.
- R1 hardcoded cue 리스트 확장은 하지 않았다. 기존 `_is_low_specificity_rescue_key(...)` 일반 술어를 `post_alias`, final semantic reread, public promotion gate에서 소비하도록 배선했다.

## 문제 해석

- Loop399 결과에서 `11713212`는 expected `null`이지만 actual `SSS급 죽어야 사는 헌터`로 publish됐다.
- 원문 제목은 `지력 무한일 때 가장 효과 좋은 작물이 머임`이고, 본문은 `절대 SSS급 지력무한 영지를 손에 넣었다 를 쓰려는 건 아니고`로 후보작을 부정 예시처럼 사용한다.
- 댓글 흐름도 옥수수, 지력, 귀농물 등 일반 농사/설정 대화에 가깝다.
- 기존 경로는 `official_url_recall_blocked_relation_non_work_context`, `batch_memory_alias_rescue_blocked_after_title_deliberately_null` 흔적이 있었는데도, `post_alias_official_detail_bridge_anchor`와 `confirmed_alias:가장`이 final semantic demotion을 막고 public gate를 `current_work`로 통과시켰다.

## 코드 변경

- `src/llm_batch/agentic_pipeline.py`
  - `_has_low_specificity_alias_nonwork_context_block(...)`를 추가했다.
  - relation non-work, deliberate-null, semantic no-work 흔적이 있고 후보의 alias가 `_is_low_specificity_rescue_key(...)`에 해당하면 work bridge를 차단한다.
  - `_post_discusses_work_as_work(...)`가 이 helper를 먼저 경유하도록 배선했다.
  - `_has_post_alias_official_detail_bridge_anchor(...)`가 저특이 alias를 raw alias로 받지 않도록 했다.
  - `_should_keep_final_semantic_resolution_after_official_recall_anchor(...)`가 같은 차단 술어를 사용해 final semantic demotion을 더 이상 official recall로 되돌리지 않게 했다.
  - `_record_resolved_public_title_gate_decision(...)`와 `_can_promote_title_after_semantic_no_work(...)`가 `low_specificity_alias_nonwork_context` reason code를 남기고 scope를 `context_only`로 내린다.
- `tests/test_title_lead_search_inferred_guard.py`
  - `11713212` 구조를 재현하는 batch alias semantic no-work negative 계약을 추가했다.
  - final semantic reread official recall guard가 같은 저특이 alias/non-work 조건을 keep하지 않는 계약을 추가했다.
