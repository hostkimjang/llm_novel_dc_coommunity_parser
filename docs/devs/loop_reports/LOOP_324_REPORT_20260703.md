## 3) 연구 및 근본 원인

- registry-only alias 추가는 충분하지 않았다. `절꺾않`처럼 webtoon/소설 cross-media cue가 있는 행은 shared work bridge로 개선됐지만, OCR 표지/문장형 후보와 검색 degraded가 섞인 행은 여전히 publication gate에서 막힌다.
- `괴담출근`은 Loop323에서 safe-resolved였으나 Loop324에서 search degraded와 OCR/명시 제목 미해결 경로로 떨어졌다. 동일 packet safe_resolved 단조 비감소 조건을 만족하지 못하므로 residual decrement가 아니다.
- `빌환`은 Arbiter가 `빌어먹을 환생`을 Max confidence로 잡았지만 final serialized identity는 `promotion_blocked`로 남았다. `PromotionDecision`과 최종 serialize trace 불일치 후보로 다시 봐야 한다.
- `성좌안무서움`은 등록 약칭 힌트가 있어도 OCR 문장형 제목과 충돌했다. 이 행은 약칭 gate 완화보다 image/OCR title-role 분리와 공식 detail URL anchor의 우선순위 조정이 필요하다.
