## 3. 연구·근본원인 분석

원인은 gallery-homage bridge 자체가 아니라 마지막 결합 조건이었다. `_known_title_abbreviation_fictional_gallery_homage_bridge_context(...)`는 verifier의 `explicit_alias`, `specific_work`, community alias support를 확인했지만, `_has_curated_alias_contextual_work_anchor(...)`는 그 뒤에도 `has_positive_semantic_cue`를 요구했다. 이 때문에 작품 안에서 갤러리/댓글식 커뮤니티를 다루는 웹소설 표면이 `community_banter`로 분류되면 정당한 alias bridge가 닫힐 수 있었다.

보정은 title/post_id 전용 예외가 아니라 shared predicate 정렬이다. 경쟁 본문 작품 근거가 있으면 기존 `verified_character_work_links` 검사로 계속 막는다.
