# Loop499 테스트런 대시보드 부착 계약 보강 보고

Loop499는 테스트런 진행상황을 보기 쉽게 하기 위한 운영 계약 보강 회차다. 새 테스트런/검증런 추천 명령에서 `--no-dashboard`가 다시 섞이지 않도록 공통 helper를 추가했고, 요청 병렬도는 사용자 지시에 맞춰 `--parallel 16`으로 고정했다. 입력 수가 16보다 작으면 실제 worker는 manifest의 `effective_parallel`로 축소 확인한다.

## 변경

- 공통 정책 helper: `tools/test_run_dashboard_policy.py`
- 신규 테스트런 추천 명령은 `--no-dashboard`를 넣지 않는다.
- seed/probe/follow-up 생성 manifest에 dashboard contract를 기록한다.
- dashboard URL은 `http://127.0.0.1:8080`로 기록한다.
- 이미 시작된 run은 `tools/attach_manifest_dashboard.py --manifest <manifest>`로 사후 부착한다.
- safe-loss flip probe는 `--no-dashboard`가 expert arg로 들어와도 계획 생성 시 제거하고, 각 repeat run에 attach 명령을 함께 남긴다.
