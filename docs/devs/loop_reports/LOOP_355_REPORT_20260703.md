## 기술 요약

- 적용 범위: `11698890`, `11700500`, `11705252`.
- 구현: `KNOWN_TITLE_ABBREVIATIONS`를 더 늘리지 않고, 이미 등록된 alias가 글 안의 작품 내부 `장면/전개/최강자/강자라인/주인공` cue와 결속될 때만 official detail recall을 통과하도록 보강했다.

- Queue 결과: runtime replay는 아직 재시도하지 않았으므로 residual action queue는 `105` 그대로다.
