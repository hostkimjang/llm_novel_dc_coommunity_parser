# Loop541 Loop540 verdict의 shared-gate contract plan 전환

Loop541은 Loop540의 source-native verdict를 ordinary residual replay로 넘기지 않고 shared promotion gate 계약 큐와 plan으로 전환한 회차다. 새 runtime replay, bounded run, full375 대형 런은 실행하지 않았다.

## 변경

- `tools/build_canonical_post_verdict_contract_queue.py`
  - Markdown의 과거 `22/22` 하드코딩을 현재 application row 수 기반으로 일반화했다.
- `tools/build_post_verdict_promotion_gate_contract_plan.py`
  - Markdown의 `Loop530` 고정 문구를 post-verdict 일반 계약 문구로 바꿨다.
- `tools/build_title_mismatch_verdict_contract_plan.py`
  - title mismatch verdict `ACCEPT/HOLD/REPROCESS`를 shared `can_publish_title` gate 입력으로 변환한다.
  - `ACCEPT`도 expected audit update/exclusion 계약일 뿐 runtime approval로 승격하지 않는다.
  - `HOLD`는 native-web disambiguation, `REPROCESS`는 canonical cleanup/URL correction blocker로 유지한다.
- `tests/test_build_title_mismatch_verdict_contract_plan.py`
  - `ACCEPT`, `HOLD`, `REPROCESS`, invalid label 계약을 고정했다.
