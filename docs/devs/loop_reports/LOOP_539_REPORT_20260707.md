# Loop539 shared-gate repair queue와 canonical recheck batch

Loop539는 Loop538 expected-title 실패 `14`건을 단건 replay하지 않고, shared promotion gate architecture 기준으로 다음 작업 단위를 나눈 회차다. 새 runtime replay나 full375 대형 런은 실행하지 않았다.

## 변경

- `tools/build_canonical_candidate_recheck_batch.py`
  - `B1_missing_candidate_alignment_review`를 합법적인 canonical candidate rebuild/recheck lane으로 지원한다.
  - 이 lane에서는 `current_projection_candidate` 누락 자체를 validation issue로 보지 않는다.
  - 허용 verdict를 `EXPECTED_SOURCE_NATIVE_TITLE_CONFIRMED`, `INSUFFICIENT_EVIDENCE_HOLD`로 제한해 존재하지 않는 current candidate를 승인하지 않게 했다.
- `tests/test_canonical_candidate_recheck_batch.py`
  - missing-candidate B1 row가 validation issue 없이 review packet으로 들어가는 계약을 추가했다.
