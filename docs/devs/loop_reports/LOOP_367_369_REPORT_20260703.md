이번 코드 계약은 `ctx.verified_character_work_links` 또는 title candidate에 정답 작품이 검증된 상태로 남아 있을 때만 작동한다. Loop368에서는 이 조건이 충족되어 pre-gate 후보가 정답으로 들어왔고, stale gate 재수렴 문제가 드러났다. Loop369에서는 검색 결과가 반복 degraded되면서 `세드릭`과 `가챠펑크`가 `아카데미 생존 갤러리` 쪽 증거로 다시 합성되었고, 정답 작품 후보가 verified competing work로 유지되지 못했다.
