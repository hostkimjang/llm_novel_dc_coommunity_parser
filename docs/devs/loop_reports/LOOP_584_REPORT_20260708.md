# Loop584 test-run dashboard audit gate 보강

Loop584는 새 runtime replay, bounded run, full375 대형 runtime run을 실행하지 않고, 테스트런 진행상황을 web dashboard로 보겠다는 운영 계약을 사후 감사까지 확장한 회차다.

## 변경

- `tools/audit_goal_test_run_contract.py`가 manifest의 `dashboard_enabled`, `dashboard_mode`, `dashboard_url`, `dashboard_standalone_forwarding`, `dashboard_start_error`를 관측한다.
- 소규모 goal/test run에서 `dashboard_enabled=false`는 `NO-GO`다.
- Dashboard 필드가 없어 부착 여부를 확인할 수 없으면 `REVIEW`다.
- Markdown 감사 출력에도 dashboard 관측값을 남긴다.
- `tests/test_goal_test_run_contract_audit.py`에 정상 dashboard manifest helper와 `missing -> REVIEW`, `disabled -> NO-GO` 계약 테스트를 추가했다.

## 검증

- `python -m unittest tests.test_goal_test_run_contract_audit tests.test_run_independent_plan -v`: PASS, `24` tests.
- `python -m py_compile tools\audit_goal_test_run_contract.py tools\run_independent_plan.py tools\test_run_dashboard_policy.py`: PASS.
- Dashboard health/status: PASS. `http://127.0.0.1:8080/api/health`는 `ok=true / standalone=true / pid=9320`이고, `/api/status`는 마지막 Loop564 `30/30`, `parallel_count=16`, `batch_running=false`다.

## Gate

- dashboard audit: `GO_CONTRACT_ENFORCED`
- runtime replay: `NOT_RUN`
- full375 collateral: `NO-GO / raw 85 / runtime counts missing`
- semantic_quality: `REVIEW-LOCKED`
- full_scan_approval: `false`
- goal: `ACTIVE / NOT_COMPLETE`

완료 기준은 계속 `full375 collateral GO + full_scan 경로 정의`다. Dashboard는 진행 관측 도구이며 approval 근거가 아니다.
