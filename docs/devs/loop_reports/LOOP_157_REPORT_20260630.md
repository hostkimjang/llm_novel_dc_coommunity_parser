## 3. 연구 / 근본 원인 분석

Root cause는 stable alias correction의 evidence role 판정이 너무 느슨했던 것이다. 실제 expert 흐름은 다음과 같았다.

- Decoder/Verifier/Synthesizer/Arbiter는 `가챠펑크`와 `세드릭`을 `가챠 중독자의 퓨전펑크 생활`로 강하게 연결했다.
- `상남자`는 원문 `시원시원한 상남자라서` 안에서 캐릭터 성격 묘사로 쓰였다.
- 그러나 후단 correction이 `상남자`의 별도 official/search title 후보 존재를 stable alias conflict로 해석하여 public title을 `상남자 [독점]`으로 교체했다.
- 기존 unit coverage는 descriptor-only packet만 막았고, high-fit descriptor + low-fit title interpretation이 섞인 packet은 놓쳤다.

수정은 post_id/title 하드코딩이 아니라 Decoder interpretation의 `context_fit` 구조 신호를 사용한다.
