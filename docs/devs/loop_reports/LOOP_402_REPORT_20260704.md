  - `_pick_promotable_direct_image_work_title_candidate(...)`는 canonical 치환 시 `alias_or_mention`에 `public canonical variant` 흔적을 남긴다.

  - 검색 bridge가 있으면 `전 버두바가 하고 싶으데요`가 `전 버튜버가 하고 싶은데요`로 수렴하고, bridge가 없으면 OCR 원표면을 임의 보정하지 않음을 고정했다.
