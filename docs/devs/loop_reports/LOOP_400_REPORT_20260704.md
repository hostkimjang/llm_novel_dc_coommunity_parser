- 날짜: 2026-07-04
- 기준 HEAD: `934cb151`
- 범위: 신규 full375/bounded/N5/golden18 대형 런과 동일 38-row parent packet replay는 발주하지 않았다.
- 목적: Loop399 golden18 실패 `11698880`에서 `아생갤 -> 아카데미 생존 갤러리`가 resolved public title 경로로 publish되는 문제를 런 반복 없이 단위 계약으로 막는다.

## 문제 해석

- Loop399에서 `11698880`은 expected `가챠 중독자의 퓨전펑크 생활`이지만 actual `아카데미 생존 갤러리`로 오귀속됐다.
- 기존 title-led/batch gate는 `verified_character_work_links`나 competing candidate가 보존될 때는 body competition을 막을 수 있었다.
- 이번 실패는 정답 후보가 final `title_candidates`에 남지 않은 상태에서, post title의 `아생갤` 별칭과 검색 공식 detail만으로 `resolved_public_title_scope`가 `current_work`로 통과한 경로다.
- 본문에는 `가챠펑크 세드릭`처럼 후보 제목과 분리된 modifier+character anchor가 있었지만, 이 표면이 current title의 body bridge나 competing candidate 보존으로 이어지지 않았다.

## 코드 변경

- `src/llm_batch/agentic_pipeline.py`
  - `_has_unresolved_body_compound_character_anchor(...)`를 추가했다.
  - 이 helper는 body/comment에 current title/alias 표면이 직접 없고, current title에 대한 strong verified character link도 없으며, decoder/entity mention에 body-local modifier+character anchor가 남아 있으면 unresolved body work anchor로 본다.
  - `_record_resolved_public_title_gate_decision(...)`에 body competition 회계를 추가했다.
  - verified competing body work가 있으면 `body_verified_character_work_competes_with_resolved_public_title`로 scope를 `context_only`로 내린다.
  - 정답 후보가 보존되지 않아도 unresolved compound character anchor가 있으면 `unresolved_body_character_work_anchor`, `missing_body_work_bridge`로 publish를 막는다.
- `tests/test_title_lead_search_inferred_guard.py`
  - `11698880` 구조를 재현하는 resolved-public-title negative 계약을 추가했다.
  - current alias가 body에 직접 있는 positive control도 추가해 정상 title alias 감상글은 유지한다.
