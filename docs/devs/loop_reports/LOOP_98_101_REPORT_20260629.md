## 3) 연구 / 근본원인 분석

근본 버그는 stable alias conflict correction이 Decoder가 `general_noun`으로 본 descriptor alias를 제목 후보처럼 취급해, 더 강한 `가챠 중독자의 퓨전펑크 생활` 후보를 `상남자 [독점]`으로 치환한 것이다.

수정은 `src/llm_batch/agentic_pipeline.py`의 `_stable_batch_alias_conflicts_with_official_title()` 앞단에 `_decoder_treats_alias_as_non_title_descriptor()`를 넣어 해결했다. Decoder term이 정확히 alias와 일치하고, interpretation/candidate/best_match가 제목 후보 없이 descriptor/common-noun 계열이면 stable alias correction을 실행하지 않는다. 반대로 Decoder가 실제 title alias로 해석하는 케이스는 기존 동작을 유지하도록 positive-control 테스트를 추가했다.
