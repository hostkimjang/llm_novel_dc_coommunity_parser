# Loop236 URL-Title 직접 지지 가드 보고서

## 결론

Loop236은 목표 완료가 아니라 `11663540` focused architecture proof다. 원 canary는 `url_title_verified_official_detail`가 너무 넓어 잘못된 Novelpia URL `https://novelpia.com/novel/427233`와 제목 `두 문명과의 충돌은, 그 누구도 예상하지 못하게 일어난다 (필력 구림)`을 publish할 수 있음을 드러냈다. 수정 후에는 같은 산출물이 `official_detail_url_missing_direct_source_support`로 demote되고, patched canary Loop236b는 정답 `전 버튜버가 하고 싶은데요` / `https://novelpia.com/novel/275975`를 publish했다.

## 변경

- `expert_main.py`의 final publication ledger contract에 URL-title 직접 지지 가드를 추가했다.
- 같은 URL의 검색 title만 맞는 후보는 publish precondition이 아니다. 게시글 제목/본문/댓글/OCR/alias 중 하나가 후보 제목을 직접 지지해야 `url_title_verified_official_detail`가 열린다.
- 이미 publish된 bad `url_title_verified_official_detail` 산출물도 후처리에서 `promotion_blocked`로 내리는 demotion contract를 추가했다.
- 회귀 테스트를 추가해 `generic matched_clue` + same-URL search title 조합은 보류되고, 직접 OCR/source support가 있는 정답 URL만 publish됨을 확인했다.
