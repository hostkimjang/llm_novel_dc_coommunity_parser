## 3. 연구 / 근본 원인 분석

Loop159의 root cause는 `가챠펑크`가 작품 약칭으로 볼 여지가 있는데도, Discourse semantic seed review가 `gaming(high)`로 보고 search suggestion을 제거한 뒤 Gatekeeper noise path가 조기 종료한 것이다. 이 때문에 이후 batch alias rescue가 `가챠펑크 -> 가챠 중독자의 퓨전펑크 생활`을 알고 있어도 `semantic_seed_no_work_context`로 막혔다.

Loop161 패치는 이 경로를 다음 조건으로만 열었다.

- 게시글에 image/VLM context가 있다.
- Gatekeeper가 `title_as_body_continuation`을 잡았다.
- Gatekeeper 또는 Discourse의 정확한 query/suggestion이 제목 선두 약칭과 일치한다.
- 약칭 표면이 title/term/suggestion 쪽에 실제로 존재한다.

이 조건을 만족하면 `gaming(high)`이어도 `non_novel_short_alias_probe(...)`로 조기 종료를 보류하고, semantic seed demotion으로 검색 요청이 비어 있을 때 `가챠펑크`를 auto seed로 되살린다. 반대로 `랫따싶 림월드` 같은 game-context query는 새 테스트에서 거부한다. 기존 alias-only nonwork forced-upgrade guard도 통과했으므로, 단순 별칭만으로 비작품 문맥을 강제 승격하는 경로는 유지되지 않았다.
