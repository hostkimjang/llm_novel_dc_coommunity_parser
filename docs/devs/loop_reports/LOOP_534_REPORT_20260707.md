# Loop534 테스트런 대시보드 기본 부착 보강

이번 회차는 새 runtime replay가 아니라 테스트런 실행 정책 보강이다. 사용자가 진행상황을 보기 쉽게 하라고 지시했으므로, `tools/run_independent_plan.py`의 `run_plan()` API 기본값까지 dashboard ON으로 맞췄다. 이제 CLI뿐 아니라 도구/테스트가 `run_plan()`을 직접 호출해도 명시적으로 끄지 않는 한 standalone dashboard를 시작하거나 기존 dashboard에 forwarding env를 붙인다.

## 변경

- `tools/run_independent_plan.py`: `run_plan(..., dashboard=True)`가 기본값이다.
- `tests/test_run_independent_plan.py`: watchdog 환경변수 테스트는 `dashboard=False`를 명시하고, dashboard 기본 ON 테스트는 별도 `dashboard=True` 없이 `DASHBOARD_URL`, `DASHBOARD_PORT`, `EXPERT_DASHBOARD_FORWARD=1`, `--no-dashboard` 제거를 확인한다.
- 산출물: `docs/devs/loop534_test_run_dashboard_default_on_state_20260707.json`
