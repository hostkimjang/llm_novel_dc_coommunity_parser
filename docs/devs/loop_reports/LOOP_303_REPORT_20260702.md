- Goal 상태는 `ACTIVE / NOT_COMPLETE`다.
- Docker Desktop 재기동 뒤 search shard runtime은 복구됐다. `3333/3334` health는 `status=ok`, `headless_search_enabled=true`이고 MCP bridge 컨테이너 `36`개가 떠 있다.
