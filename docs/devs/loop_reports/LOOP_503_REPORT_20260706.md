# Loop503 테스트런 대시보드 지침 정합화 보고

Loop503은 새 대형 런을 발주한 회차가 아니다. 사용자가 테스트런 진행상황을 보기 쉽게 웹 대시보드를 붙이라고 재확인했기 때문에, 이미 Loop499/501에서 구현된 운영 계약을 문서 지침까지 정합화했다.

핵심 규칙은 새 테스트런/검증런은 기본 `--parallel 16`을 요청하고, `--no-dashboard`를 기본으로 넣지 않는다는 것이다. 입력이 작으면 실제 worker는 manifest의 `effective_parallel`로 낮아질 수 있다. 웹 대시보드는 진행 관측 도구이며 semantic/full_scan approval 근거가 아니다.
