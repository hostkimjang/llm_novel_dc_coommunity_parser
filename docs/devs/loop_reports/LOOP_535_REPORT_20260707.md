# Loop535 post-verdict expected-restore projection contract

Loop535는 Loop533에서 pending이던 expected-restore `3`건을 shared `PromotionDecision` 기반 projection contract로 적용한 회차다. 새 runtime replay는 실행하지 않았다. 적용 대상은 `11660271`, `11706871`, `11679547`이며, 기존 wrong/current projection candidate는 public identity로 내보내지 않고 `superseded_projection_candidate`로 보존했다.

## 변경

- `src/llm_batch/promotion_gate.py`: `build_publish_contract_trace()`, `build_publish_ledger()` helper를 추가해 `PromotionDecision`, `publish_contract_trace`, `publish_ledger` 생성 계약을 공통화했다.
- `tools/apply_post_verdict_expected_restore_projection_contract.py`: Loop532 contract plan의 `expected_title_restore_contract_case`만 projection identity에 적용한다.
- `tests/test_apply_post_verdict_expected_restore_projection_contract.py`: restore 적용, non-restore 무변경, missing projection row validation을 검증한다.
